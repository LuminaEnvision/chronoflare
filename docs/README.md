## History is preserved, not current instructions

The [original blueprint](blueprint-v1.2.md), delivery reviews, old handoff requests,
[v1 diagnostics](harmonization-diagnostics.md) and [dated status reports](project-status/README.md)
record earlier stages. Their pending items and test counts are historical. They
must not be used to infer that current harmonization is blocked, or that every
original seasonal/global feature was implemented.

The original owner replies, registration, thresholds, decision, frozen models,
metric JSON, data exports and dated PDF/Word snapshots are not rewritten by a
narrative documentation audit. Current summaries link those records explicitly.

The [documentation audit](documentation-audit.md) records the corrections and remaining checks.
